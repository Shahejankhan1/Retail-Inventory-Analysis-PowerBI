# Retail Inventory Analysis Dashboard

## Project Overview
This project provides an interactive Power BI dashboard for analyzing retail inventory, sales, profit, customers, and regional performance.

## Objectives
- Monitor sales performance
- Analyze profit trends
- Track inventory status
- Identify top products
- Support business decision making

## Tools Used
- Power BI
- Excel
- DAX
- Power Query

## Dashboard Features
- KPI Cards
- Drill Through
- Tooltips
- Bookmarks
- Dynamic Filters
- Business Commentary

## Key Metrics
- Total Sales
- Total Profit
- Profit Margin
- Order Count
- Category Performance
